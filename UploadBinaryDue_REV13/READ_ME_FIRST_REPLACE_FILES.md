# READ ME FIRST - Replacement Instructions

This ZIP is the clean replacement set for your GitHub `UploadBinaryDue_REV13` folder.

Do this:

1. Open your existing `UploadBinaryDue_REV13` folder.
2. Keep your existing `bossac.exe` file.
3. Delete the other old files in that folder.
4. Copy all files from this ZIP's `UploadBinaryDue_REV13` folder into that same folder.
5. The final folder should contain your existing `bossac.exe` plus these corrected files.

Do not copy/paste the script text into GitHub's editor.
Upload these actual files, or drag/drop the actual files, so the script line breaks stay correct.

PowerShell flash command:

```powershell
.\upload.bat COMX
```

Example:

```powershell
.\upload.bat COM7
```
